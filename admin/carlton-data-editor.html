Publishing your changes

  1. Start from the current data. This tool loads the live data from the site when it opens. If you've had it open for a long time, reload it before you start.
  2. Make your changes. They stay in this browser tab until you send them, so don't close it.
  3. Press "Send changes". Give your name and, if you like, a short note about what you changed, e.g. "Coordinates for Barry Street, 1905". Then press Send.
  4. The editors check them. Your changes go to the editorial team's spreadsheet, where an editor accepts or rejects them. Once accepted, the live site shows them a minute or two later. Until then the site (and this editor, if you reload it) still shows the old data.

If someone else changed the same records after you opened the editor, nothing is sent and you'll be asked to reload. Use Download changed files first if you want to keep a copy of your work.

Advanced: download and upload by hand

The data is kept as one file per source and year, e.g. _data/directory/1905.json or _data/electoral-roll/1919.json. You only need to upload the files you changed. You don't need any special software — this is all done in your browser.

  1. Make sure you started from the current data. This tool loads the live data from the site when it opens. If someone else published changes since you opened it, reload the page before editing so you don't overwrite their work.
  2. Download the changed files. Click "Download changed files". It lists each file you changed, with a Download button for each, e.g. 1905.json.
  3. Check the filenames. Look in your Downloads folder. If your browser saved a file as 1905 (1).json or similar, rename it back to exactly 1905.json — it must match the existing file's name.
  4. Open the upload page for that file's folder: the list gives a link for each one (it opens GitHub's Upload files page for _data/directory or _data/electoral-roll). Sign in if needed.
  5. Drag your downloaded file into the box. GitHub will recognise it has the same name and replace the old one. Files for the same folder can go up together.
  6. Scroll to the bottom of the page. Under "Commit changes", type a short note describing what you changed, e.g. "Add electoral roll entries for Barry Street, 1928".
  7. Make sure "Commit directly to the main branch" is selected, then click Commit changes.
That's it — your changes are now in the repository. The live site takes a minute or two to update after you commit.

If you add a record for a year that has no file yet, the list will say so: a new year also needs a small page file before the site will show it, so ask a developer to add it (the README explains how).

If you're ever unsure whether your edits "took", reload this page once the site has updated and check the records look as you expect.
