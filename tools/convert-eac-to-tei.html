Convert entries from EAC-CPF to TEI

A one-off tool for the move to TEI (README roadmap §4). It reads every entry in civic/ that is still EAC-CPF, converts it with the same code as the contribution form (scripts/tei.js), and offers each result for download. Upload the files to civic/ on a branch, replacing the old ones.

It keeps the title, the authors, the date and description of the original submission, and the article. The type of each entry comes from the list in this page (KINDS); EAC-CPF said concept for everything. The boilerplate eMelbourne citation (resourceRelation) that every old entry carries is left out.
